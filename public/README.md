# Математика онлайн — освітній вебресурс

Статичний вебзастосунок для навчання математики у 5–11 класах: теоретичні відомості,
інтерактивні візуалізації, тренувальні завдання з параметричною генерацією та підсумкові тести.

Серверної частини немає. Прогрес користувача зберігається в `localStorage` браузера
й нікуди не передається.

## Структура

```
index.html        головна: пошук за темами, навігація за класами
class.html?c=9    перелік тем класу
topic.html?t=ID   сторінка теми: теорія → візуалізація → завдання → тест
visuals.html      каталог візуалізацій;  ?v=ID — окрема модель на весь екран
trainer.html      наскрізна практика;    ?t=ID — одразу на потрібній темі
progress.html     статистика, динаміка, експорт звіту
teacher.html      методичні рекомендації та інструкції

css/style.css     усі стилі (Flexbox/Grid, mobile-first, без фреймворків)
data/topics.js    каталог тем: теорія, прив'язка візуалізації, набори генераторів
js/core.js        утиліти, ГПВЧ, робота з localStorage, прогрес
js/tasks.js       30 генераторів завдань (параметричні шаблони)
js/check.js       перевірка відповідей, зокрема еквівалентності виразів
js/practice.js    тренажер і підсумковий тест, триступеневий зворотний зв'язок
js/vis/plot.js    полотно Canvas 2D: сітка, осі, криві, точки
js/vis/*.js       шість візуалізацій
vendor/           KaTeX і Chart.js локально (щоб ресурс працював без CDN)
```

## Як запустити локально

Сторінки використовують модулі ES, тому відкривати `index.html` як файл не можна —
потрібен будь-який локальний сервер:

```bash
cd public
python3 -m http.server 8080
# відкрити http://localhost:8080
```

## Розгортання на GitHub Pages

```bash
git init
git add .
git commit -m "Освітній вебресурс з математики"
git branch -M main
git remote add origin https://github.com/<користувач>/<репозиторій>.git
git push -u origin main
```

Далі в налаштуваннях репозиторію: **Settings → Pages → Source: Deploy from a branch**,
гілка `main`, папка `/ (root)` — якщо вміст `public/` лежить у корені репозиторію.
Альтернатива — Vercel: `vercel --prod` із каталогу `public`.

## Перевірка

`test.mjs` (рівнем вище) піднімає локальний сервер і проганяє Playwright:
обхід усіх сторінок, перевірка 30 генераторів по 60 варіантів кожного,
перевірка еквівалентності виразів, наскрізний сценарій відповіді на завдання
та контроль адаптивності від 320 px.

```bash
npm install playwright
node test.mjs
```

## Як додати нову тему

1. Додати об'єкт до масиву `TOPICS` у `data/topics.js`: `id`, `cls`, `subject`, `title`,
   `short`, `program`, `vis`, `theory`, `gens`, `test`.
2. За потреби додати генератори завдань до `GEN` у `js/tasks.js`.
3. Якщо потрібна нова візуалізація — створити модуль у `js/vis/` з експортом
   `mount(host, opts)` і зареєструвати його в `topic.html` та `visuals.html`.

## Відомі обмеження

- охоплено частину тем курсу, а не всю програму 5–11 класів;
- прогрес не переноситься між пристроями (немає серверної частини);
- перевірка математичних виразів розпізнає не всі еквівалентні форми запису;
- динамічні побудови GeoGebra підвантажуються із зовнішнього сервера й потребують
  інтернет-з'єднання; решта матеріалів працює без нього.
